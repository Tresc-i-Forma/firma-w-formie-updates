# Firma w Formie: wydania

Księgowość jednoosobowej działalności od [Treść i Forma](https://tresciforma.pl).

To repozytorium zawiera tylko gotowe wydania programu (bez kodu źródłowego).

- **Nowa instalacja:** pobierz `Firma-w-Formie-Setup-<wersja>.exe` z
  [najnowszego wydania](https://github.com/Tresc-i-Forma/firma-w-formie-updates/releases/latest).
- **Aktualizacja:** program sam sprawdza i instaluje nowe wersje (O programie → Sprawdź aktualizacje).

Program instaluje się na koncie bieżącego użytkownika, bez uprawnień administratora. Instalator nie jest jeszcze
podpisany certyfikatem, więc Windows może pokazać ostrzeżenie „nieznany wydawca”.
